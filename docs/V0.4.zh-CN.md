# V0.4 首轮：Orbit 布局与逐设备策略

状态：**早期开发 / 0.4.0.dev2**。本轮实现约束式 Orbit 编辑器，不是自由拖拽仪表盘；真机验收单独记录。

## 布局与同步

设置 → Orbit 布局可切换时钟、当天天气、圆环中心主窗口，以及舒展/紧凑间距。修改自动保存在当前浏览器，以设备 ID 区分；不含令牌或观测数据。返回即可预览，存储失败时明确提示。导出文件仅含四项布局字段，布局不能增加数据权限。

只读 `GET /api/v2/device-config` 返回当前设备名称、允许的来源、推荐布局、修订版本、更新时间和公共数据标记；没有设备写入方法，拒绝全局旧式读取令牌。旧设备默认推荐版本为 0，保持已验收外观。页面每 30 秒读取推荐；本地覆盖会保留，直到点击“恢复服务端推荐”。语言、动效仍属于本浏览器。

管理员在服务端本地执行：

```sh
pixora-device --db /data/pixora.sqlite list
pixora-device --db /data/pixora.sqlite inspect DEVICE_ID
pixora-device --db /data/pixora.sqlite configure DEVICE_ID --profile examples/device-profiles/compact.json
pixora-device --db /data/pixora.sqlite configure DEVICE_ID --policy examples/device-profiles/system-cpu-only.json
```

示例中的连接器和实体 ID 必须替换为实际允许的对象。网页导出 JSON 可作为 `--profile` 输入。只传一个文件时保留另一类配置；严格验证后原子递增版本。文件上限 16 KiB。`list`/`inspect` 不输出原始令牌；未开放公网管理员 API。

## 权限收紧规则

- `rules: null` 默认保留原授权；`rules: {}` 拒绝所有来源；非空映射是来源白名单，始终与原始令牌范围取交集，CLI 拒绝扩权。
- 每个来源可限制 `connectors`、`entities`、`metrics`、`windows`；`null` 为原范围内不额外限制，`[]` 为该维度全拒绝。仅精确匹配，不支持正则和通配符。
- `entries` 为 `full`、`titles`（移除详情和 URL）或 `none`。已授权对象的来源、实体、状态、时间戳等标准信封字段仍可见；不是任意 JSON 字段 ACL。
- `public_only: true` 只返回采集端标为 public 的观测。v1 额度没有公共分类，全部不返回；只有可信写入端能分类。浏览器“共享屏幕”另外退出登录并隐藏内容，不是服务端策略编辑器。
- 当前数据、历史、v1 额度均在服务端过滤；Bearer 和已有 Cookie 会话每次请求读取最新策略。历史先按实体/连接器/公共标记筛选，再分页，随后投影指标和条目。不会先下载私密数据再靠 CSS 隐藏。
- v1 额度对应 `quota-v1` / `default`，`windows` 和 `metrics` 同时约束窗口名；v2 使用同名指标。只授权周额度时，不会误标成 5 小时额度。

## 升级与回退

新增独立 `device_profiles` 表，原设备行、令牌摘要、会话和历史保留策略不变。升级前通过 SQLite backup API 备份并检查完整性。无配置行的旧设备保留原读取行为；先在隔离或临时设备验证策略，不在升级时自动修改手机授权。

**隐私回退边界：** V0.4 之前的服务不会识别新策略。回退前必须撤销所有启用限制策略的活动设备，或继续使用支持 V0.4 策略的服务；否则原来较宽的授权可能重新可读。恢复旧数据库还会恢复旧撤销/会话状态，需要单独恢复方案。仅推荐布局不属于限制策略。

## 后续任务

网页管理员设备清单、配对/撤销、授权远程发布、多个屏幕分配、更丰富组合仍待做。显示端保持只读，无凭据或控制扩权；本轮不宣称完整字段策略工具、自由拖拽和稳定 Release 已完成。

## 主题增量（dev2）

新增 `theme`（orbit/paper/amoled/aurora）、`accent`（mint/blue/amber/violet）、`text_size`（standard/large）和 `appearance`（theme/light/dark/auto）。旧四字段布局自动补 Orbit 默认，不重写原记录。主题默认时 Paper 浅色、其余深色；AMOLED 仅深色模式为纯黑。“跟随系统”响应页面打开期间的系统变化；大字调整 Orbit 展示内容，浏览器缩放仍可用。

同一套变量覆盖展示、设置、控件与状态颜色。Aurora 使用柔和渐变，可选18秒合成层位移动效；关闭动效、隐藏页面、系统减少动效均可停止，其余主题无动态背景。实际耗电未测量。明暗配色的主要文字对比度测试要求不低于4.5:1，不等于完整无障碍认证；不加载外部字体或素材，不增加远程权限。

导出、本地保存、服务端推荐均保留主题字段，示例见 examples/device-profiles/aurora.json。含新字段的服务端记录不能直接交给严格的dev1解析器。回退前需备份并仅将布局JSON转换回四个原字段，保持权限策略和授权不变，或继续使用兼容dev2的服务；旧镜像能启动不代表安全回退已验证。
