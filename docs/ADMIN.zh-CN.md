# 设备管理（V0.4 dev3）

[English](ADMIN.md) | [简体中文](ADMIN.zh-CN.md)

打开 `/?admin=1`，或设置 → 设备管理（管理员）。管理登录独立于显示端登录：普通设备令牌、旧全局读取令牌与采集写令牌都不能用于管理。没有默认密码和未认证初始化入口。

## 首次登录与恢复

在**服务器本地**创建独立管理员密钥，数据库路径须与正在运行的服务端一致：

```sh
pixora-admin --db /data/pixora.sqlite create --name owner --days 90
# Docker Compose，继承 PIXORA_DB：
docker compose exec monitor python -m pixora.admin create --name owner --days 90
```

密钥只输出一次，请私下保管，填入 HTTPS 管理页；不要贴进 URL、公开截图、Issue 或日志。浏览器不会把密钥写入本地存储。无邮件找回；遗失后从服务器本地重新创建并撤销旧密钥：

```sh
pixora-admin --db /data/pixora.sqlite list
pixora-admin --db /data/pixora.sqlite revoke KEY_ID
```

数据库只存密钥和会话摘要。管理员 Cookie 为独立的 `__Host-pixora_admin`，Secure、HttpOnly、host-only、SameSite Strict。会话最长 8 小时，且不能超过密钥期限；每个密钥最多 5 个有效会话。每次请求检查期限与撤销；退出管理不影响显示端登录。所有网页写操作要求同源 HTTPS Origin。管理员登录按进程全局限制每分钟 20 次，不是分布式防滥用；公网代理的连接/速率限制仍由部署者管理。

## 设备与配对

清单分页显示授权状态、到期时间、原始数据源权限、配置版本与未过期会话数。**“有效”指授权有效，不等于设备在线。** 每台实体屏幕应使用独立配对码；旧版复用同一配对码的多部手机无法区分。升级保留已有设备、权限及本地布局。

添加设备可选名称、数据源与 1–365 天期限，网页首轮仅创建真实模式授权；演示模式继续由本地 CLI 创建。网页最多创建 200 台未过期且未撤销设备。选择暂不可用的数据源不会生成虚假数据。

创建后仅当次返回显示令牌，用随构建捆绑的 [node-qrcode（MIT）](https://github.com/soldair/node-qrcode) 在浏览器本地生成二维码，不发送给第三方二维码服务。显示端读取链接 fragment 后立即清除地址中的令牌。**配对码在设备到期或撤销前可重复使用，不是一次性邀请。** 关闭、页面进入后台或 10 分钟后自动隐藏；隐藏不等于撤销。不要公开分享；遗失请撤销重建，列表无法找回原始令牌。

撤销需明确确认，立即使令牌及其全部已有会话失效；无法远程擦除设备已显示或离线保留的内容。修改名称和策略要求版本匹配。高级策略 JSON 只能在原授权范围内限制，遵守 [V0.4 契约](V0.4.zh-CN.md)，损坏配置拒绝发布，不回退到全权限；本轮没有可视化字段策略编辑器。

## 多屏布局发布

选中最多 20 台配置正常的有效设备，编辑布局草稿或导入显示端导出的 JSON 后发布。所有目标与版本在同一 SQLite 事务中校验，任何过期、撤销、损坏或版本冲突都会使整批失败，避免部分覆盖。发布只改布局，不改数据源权限和限制策略。可载入已有设备布局复用到其他屏幕；这仍是受约束的布局配置，不是任意拖拽组件。

显示端每 30 秒刷新时读取服务端推荐。**手机本地自定义布局仍优先**，需在该手机点击“恢复服务端推荐”，才跟随后续远程发布。管理页不会强制清除另一浏览器的偏好。导入支持所有合法布局字段及任意已解析天气城市 ID；快捷城市有采集默认、上海和得克萨斯州休斯顿。

操作记录最多保留 1000 条，页面读取最近 100 条，含管理员密钥 ID、时间、动作、设备 ID、版本或权限摘要；不记录密钥、配对码、IP 或观测内容。这是运维记录，不是不可篡改审计系统。

## 部署与回退

dev3 新增 `admin_keys`、`admin_sessions`、`admin_audit` 表，不修改已有设备记录。升级前用 SQLite backup API 备份。退回 dev2 会失去网页管理，但设备策略和撤销状态仍有效；须保持配置兼容，不要随意恢复撤销前的数据库。退到 V0.4 前版本的隐私回退限制仍适用。密钥备份须私密保存，服务器文件系统访问仍等同完整管理权限。

剩余方向：一次性邀请、强制远程布局接管、设备在线状态、可视化策略、自由 Widget 编排、多用户管理员角色。没有宣称稳定 Release 或硬件验收。
