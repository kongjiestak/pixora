# V0.6: minimal trustworthy reminders (in development)

The first increment adds opt-in, browser-local quota reminders under Settings. Defaults: low at 10% remaining, recovered at 20%, 30-minute per-event cooldown. Hysteresis and observation deduplication prevent polling noise; local-time quiet hours support overnight ranges. Suppressed transitions are not queued. History is capped at 20 summaries per paired device; clearing history retains deduplication.

Only fresh real Codex observations already authorized for that device are evaluated while the page is visible and connected. Demo, expired, unavailable, shared-screen and signed-out states cannot notify. Settings/history stay in localStorage; clearing browser data resets them. No additional server permissions or database migrations.

Not implemented: background push, system/Watch/ESP32 notifications, task-completion events, cross-device deduplication or delivery acknowledgements. Idle is not task completion. The owner deferred installing a notification receiver; Watch 8 delivery remains a later physical acceptance gate. This increment is not a completed V0.6 release.

Run `npm --prefix web test` and `npm --prefix web run build`. Optional browser acceptance: `node web/e2e/quota-alerts.mjs` with Playwright/Chromium installed (or set `PIXORA_PLAYWRIGHT_MODULE` and `PIXORA_CHROME`). The test uses an isolated local HTTPS fixture and synthetic API responses, never production devices or real quota changes.
