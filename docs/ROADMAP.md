# V0.1–V1.0 路线图

以验收条件推进，不承诺固定日期。

| 版本 | 目标 | 验收门槛 |
|---|---|---|
| V0.1 | Mac→SQLite→Web/PWA 最小闭环；Widget/主题/布局/设备本机设置 | 真实额度实测或明确失败；鉴权/过期/演示隔离测试；可构建交付 |
| V0.2 | 通用 Observation v2、主机/PVE 只读连接器、历史与迁移 | 老数据迁移可回滚；首个系统 Widget 闭环 |
| V0.3 | 开发者与个人信息首批模块：CI、CalDAV、待办、天气/RSS | 每模块来源/过期/权限；真实 Android/iOS 兼容矩阵 |
| V0.4 | 编辑器、服务器设备配置、单设备令牌撤销与字段裁剪 | 公共屏幕无法通过 API 获取私人字段；备份恢复验证 |
| V0.5 | 个人信息深度扩展：邮件摘要、生活/账单提醒、通勤、预算、目标 | 数据最小化、连接器授权撤销、敏感屏幕锁 |
| V0.7 | 自动化预览、独立控制权限、确认与审计 | 幂等、防重放、失败可解释；只读设备无法控制 |
| V0.9 | ESP32 多尺寸适配、低性能终端优化、可靠更新 | 固件/网页协议兼容与断线恢复；硬件实测 |
| V1.0 | 稳定协议与插件 SDK、权限、迁移、文档和发布 | 端到端兼容矩阵、恢复演练、安全审查、可复现发布 |

NFC、MagSafe、自研 PCB 单列硬件探索，在软件接口稳定、需求及安全验证后决定版本。
