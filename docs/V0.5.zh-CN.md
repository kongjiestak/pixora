# V0.5 首屏原型

[English](V0.5.md) | [简体中文](V0.5.zh-CN.md)

路线聚焦自托管跨设备 AI 状态与提醒。取消旧 V0.5 个人信息扩展；现有天气/时钟/系统/GitHub/RSS保留可选。V0.4用户已验收。后续V0.5首板+手机引导、V0.6真实活动/少量提醒+Watch8通知验证、V0.7小白上手/恢复、V1.0稳定收敛；不承诺原生手表App或所有手环兼容。

原创 ESP-IDF/LVGL 客户端位于 [firmware/esp32](../firmware/esp32/README.zh-CN.md)。第一门槛为可构建与数据语义正确，不以此冒充硬件适配。直接复用既有HTTPS只读设备API，无需新服务端入口、上游凭据或生产部署。首版不含Web主题/推荐布局/天气同步；屏幕英语，配网页中英文，仍需手动打开AP页面。

用户接入的微雪 ESP32-S3-Touch-AMOLED-2.16 已识别为S3 rev0.2、16 MiB Flash、8 MiB内置PSRAM，原始全片已备份并与实物摘要校验。安全信息显示Secure Boot/Flash Encryption未启用，本轮未修改保护或eFuse。唯一标识、备份、部署凭据均在仓库外私有目录。

已测：生产 C 额度解析器通过地址/未定义行为检测，与线上授权Codex响应的字段一致。构建、硬件和手机配网分别验收，不能继承过去Web/PWA验收结论。

本机 ESP-IDF v5.5.5 构建通过，应用镜像 1,574,768 字节（0x180770），6 MiB应用分区剩余约75%。尚未刷入设备；物理屏幕/触摸/配网等验收仍待执行。
