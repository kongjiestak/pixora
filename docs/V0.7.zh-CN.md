# V0.7：本地电脑与旧手机

状态：Early Development，第一增量已实现；不是已完成版本。V0.6 提醒与 Watch 验证暂停。

## 本轮可运行内容

- `pixora-local` 在电脑本地启动 FastAPI、SQLite 与 Codex 真实额度采集。无需 Docker、NAS、VPS。
- 独立私有数据目录；随机写入凭据与只读屏幕凭据分离；关闭旧全局读令牌。
- 私有扫码页包含只读屏幕授权，30 天到期；被撤销/到期后再次启动会生成新授权。
- 默认仅监听 localhost。显式指定本机私有 IPv4 才开放局域网；不自动创建公网端口映射。
- 网页新增伙伴视图：原创新像素图形、工作/空闲/异常/未知、中英文、主题色、点击挥手、动效开关与减少动态效果。
- 本地活动接口默认关闭，仅本地启动器开启。5 秒轮询、15 秒过期，不上传提示词、聊天 ID 或路径。实验性本机事件来源不等同全账号状态。

## 交付包启动

含 `web/dist` 的交付压缩包解压后，Mac 可运行 `Start-Pixora.command`，Windows 可运行 `Start-Pixora.cmd`。仍需自行安装 Python 3.11+ 和已登录的 Codex CLI；首次启动需要联网下载 Python 依赖。启动脚本会创建独立 `.venv-local`，不要求 Node.js 或 Docker。Windows 启动脚本与 macOS 双击交互尚未实机验收；命令行本地链路已验证。

## 源码运行（首次构建需要 Node.js）

在源码目录安装 Python 3.11+ 与 Node.js 22+，然后：

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-lock.txt
pip install --no-deps .
npm --prefix web ci
npm --prefix web run build
pixora-local
```

Windows 可使用 `py -3 -m venv .venv` 与 `.venv\Scripts\activate`。本轮没有 Windows 实机验收。

Codex CLI 需已安装并登录；否则如实显示数据不可用。不会回退为演示额度。
启动器自动打开本地私有配对页。关闭终端或 Ctrl+C 停止服务与采集器；它不会安装系统后台服务。

手机与电脑连接同一可信局域网，将下方地址换成本机实际私有 IPv4：

```sh
pixora-local --lan-address 192.168.1.20
```

扫码页含授权，勿截图分享。地址变化后需重新运行并扫码；访客网络、客户端隔离、防火墙可能阻止连接。不要将 HTTP 端口映射到公网。

局域网 HTTP 为临时显示：关闭页面后需重新扫码，不能保证常亮、离线缓存或 PWA 安装。完整体验需手机信任的 HTTPS 证书，可通过 `--cert`、`--key` 配置；采集器会验证同一证书。证书签发、信任安装与跨设备发现尚未实现，未宣称零基础完整安装完成。

数据目录默认 `~/.pixora/local`，不复用已有 VPS、家庭端或 ESP32 的数据库/凭据。可用 `--data-dir` 指定独立位置。不要上传此目录。Windows 文件 ACL 需进一步验证；POSIX 权限不能代替 Windows ACL。

## 验证与剩余门槛

2026-10-23：后端 104 通过、11 跳过（BLE 可选依赖）；网页 38 通过，生产构建通过。独立非 editable 安装在源码目录外实际启动，真实 Codex 采集返回 `ok`；只读鉴权、活动接口、私有二维码页、日志无凭据、退出释放端口通过。

独立 Chromium 合成场景通过：伙伴工作状态、挥手、中英文、手机横竖屏/平板宽度与内容分离、401 后回到未知，无页面异常。不是手机实机验收。

剩余：

1. **第一阶段**：一键安装/启动包、局域网地址选择与故障引导、可信 HTTPS/PWA 配对体验、伙伴屏偏好保存、完整 Mac/Windows 与手机实机验收；活动来源恢复和多设备权限细化。
2. **第二阶段**：隔离 USB 控制原型，验证真实请求对应的单次允许/拒绝；不模拟盲目按键，不承诺控制任意现有桌面聊天。
3. **第三阶段**：按住录音、电脑转写、屏幕预览与确认发送，之后再验证无线语音。

本轮不部署覆盖正式 VPS，不刷写已验收 ESP32，不创建稳定 Release。
