# V0.7: local computer + everyday screens

Early Development, increment 1. Quota reminders / Apple Watch work is paused.

Bundles containing `web/dist` also include `Start-Pixora.command` and `Start-Pixora.cmd`. These bootstrap a private Python environment; Python 3.11+ and signed-in Codex CLI are still prerequisites. Initial dependency installation needs Internet access. Windows and double-click UX are not yet accepted.

`pixora-local` starts an isolated local server, SQLite database and real Codex collector, then opens a private QR pairing page. No Docker or VPS is needed. Python 3.11+ is currently required; first-time Web builds require Node.js 22+.

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-lock.txt
pip install --no-deps .
npm --prefix web ci
npm --prefix web run build
pixora-local
# Explicit trusted LAN access: use an address actually assigned to this computer.
pixora-local --lan-address 192.168.1.20
```

Install and sign in to Codex CLI first. Missing data remains unavailable, never synthetic. Default binding is localhost. The private QR contains a scoped read-only credential; do not share it. Credentials/database stay in `~/.pixora/local`, separate from existing deployments. Ctrl+C stops both children. No background service is installed.

HTTP LAN pairing is temporary: re-scan after reopening. Persistent sessions, full PWA and reliable secure-context features require trusted HTTPS. `--cert` / `--key` accept an existing certificate; automatic certificate issuance/trust installation is pending. Never forward the HTTP port to the public Internet. Windows activation uses `.venv\Scripts\activate`; Windows runtime and ACL behavior are unverified.

The Web companion uses original pixel artwork, theme colors, English/Chinese labels, click-to-wave and optional motion. Experimental local lifecycle metadata is polled every 5 seconds and expires after 15 seconds. Missing, unauthorized, offline or expired activity is unknown. No prompts, paths or chat identifiers are exposed. The activity endpoint is disabled by default outside the local launcher.

Verification: 104 backend tests passed, 11 optional BLE tests skipped; 38 Web tests passed; production build passed. A clean non-editable install started outside the source tree, collected real Codex quota (`ok`), enforced read-only access, kept tokens out of logs and shut down cleanly. Synthetic Chromium checks covered companion states, wave, bilingual labels, phone/tablet viewports and authorization failure. Physical phones and Windows remain pending.
