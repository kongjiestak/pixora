# V0.5 ESP32 屏幕完善与验收

适用 Waveshare ESP32-S3-Touch-AMOLED-2.16；开发分支，不代表稳定版验收。

## 已实现

- Orbit 双环外围紧凑显示时分、月日/星期、城市/当前天气及连接状态。时间由 SNTP 或签名 Mac USB 帧校准，随后设备本地走时。无可信时间显示 `--:--`。
- 独立床头时钟页：首页 Clock/Quota 按钮或左右滑动切页；本机保存上次页面。无自动轮播。时钟每分钟微移 ±2px，降低固定显示风险，不能保证消除烧屏。
- Settings → Screen / Clock：亮度 20–100%、夜间调暗、时区、旋转。夜间模式按本机显示时区 22:00–07:00 且闲置15秒时降至8%；触摸后恢复设置亮度。
- 时区与天气城市独立。本轮可选 UTC+08 / UTC / UTC-05 固定偏移，**不是带夏令时规则的城市时区**。内部时间和额度解析始终 UTC。
- 旋转提供0/90/180/270度，保存成功后重启；由适配器旋转绘制及对应触摸映射。本轮没有自动感应旋转。
- 首页闲置15秒隐藏按钮；透明触摸层消费首次点击以唤醒，下一次点击才执行操作。设置页不自动隐藏。
- 二级菜单有 Back，密码输入页也有显式 Back / 键盘 X；取消不提交凭据。连接过程中 Back 仅离开进度页，已提交的连接仍在后台完成。
- 移除持续绕圈，只在额度改变时做350ms局部过渡，可关闭动效。相同文字不反复重绘。每10次实际绘制刷新记录均值/最大耗时；此指标不是面板物理刷新率，也不能代替视觉流畅度验收。

## 数据与权限

Wi-Fi与Mac桥接均用同一设备令牌读取既有 `/api/v1/device` 和 `/api/v2/observations`，保持TLS证书验证且禁止重定向。USB只加入天气观察，不传递其他个人观察。源为 Open-Meteo.com，CC BY 4.0；来源页保留署名。

仅展示授权返回的真实天气，校验单位、范围、采集/模型时间及到期时间。无天气权限与天气不可用分别提示；天气失败不会抹掉额度。撤销清空数据。城市沿用服务端默认采集城市；**本轮未加入ESP本机城市搜索、手机本地城市偏好同步或多天气源**。

## 实物验收（待用户确认）

1. 启动后核对时分、日期星期、天气及额度，检查外围文字无裁切/覆盖。
2. Clock切页并重启，确认记住页面；左右滑动可返回。
3. 每一级菜单测试Back；Wi-Fi密码页取消，原连接仍保留。
4. Settings → Screen / Clock修改亮度及夜间开关，重启保留；夜间时段闲置后变暗、首触只唤醒。
5. Rotation每点一次会保存并重启；四方向分别验证文字方向与Settings/Back触摸位置，最终回0度。
6. 观察额度变化时短过渡是否舒适；关闭动效后无过渡。静态显示不应持续绕圈。
7. 拔插USB自动恢复、断网/撤销状态及持续运行另外验收，不以构建/ACK代替实物画面验收。

未实现：自动旋转、时区夏令时、可编辑夜间时段、蓝牙、多Wi-Fi管理。热点直连兼容问题仍单独跟踪。
