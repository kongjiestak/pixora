# Pixora 首屏原型 — V0.5 dev1

[English](README.md) | [简体中文](README.zh-CN.md)

**这是待真机验收的原型，不是已验收固件。** 首板限定微雪 ESP32-S3-Touch-AMOLED-2.16（480×480、CO5300、16 MiB Flash、8 MiB PSRAM）。已只读识别用户实物，并将原始整片 Flash 私密备份、与设备摘要校验一致；芯片识别不等于屏幕/触摸驱动已验证。禁止将该布局用于不同型号。

客户端原创，复用 Apache-2.0 微雪 BSP、LVGL 与 ESP-IDF。评估 VibePulse 后，选择直接读取既有授权 API，避免为它的必需统计字段填充尚未采集的数据。未复制其固件、品牌或角色素材。

## 已写入源码的能力

- 使用独立显示令牌 HTTPS 读取 `/api/v1/device`，30 秒轮询。证书包/主机名校验开启，不跟随重定向；服务端权限/撤销继续有效，不上传账号凭据，无控制写入。
- 两个 Codex 剩余额度圆环、恢复倒计时、采集年龄和过期/离线提示。未知是 `--`，不是零；仅有周窗口不会被标成短窗口。离线缓存本地过期，401/403 清屏。未宣称 Claude、任务活动、天气、主题/推荐布局同步、OTA、多语言屏幕或手表能力已完成。
- 手机配网：屏上显示随机密码的 WPA2 配网二维码，连接后手动打开 `http://192.168.4.1`。可扫描并选择附近 2.4GHz 网络（最多24条扫描记录、同名去重），显示信号强度和是否加密，也可重新扫描或手动输入隐藏网络。尚未实现完整自动弹出门户。配网页中英文，屏幕首版使用英语内置字体。
- 服务地址与显示令牌来自私密 NVS 文件。高级设置可更换，但不回显保存的秘密；换服务必须提供新令牌。NVS 尚未加密，不能宣称抵御物理读取。配网 HTTP 只接受 AP 本地接口请求，不能从 STA/普通局域网接口配置；提交要求每次配网生成的随机表单校验码；接受同源或手机隐私策略产生的缺失/null Origin，拒绝外部站点来源。
- 没有初始配置时进入配网；已保存网络断开后自动重试。错误配置可触摸 Wi-Fi / Setup 重新配网。配网需保存重启才退出，尚无自动超时；错误 Wi-Fi 配置可能被保存，但有回退重试入口。真实配网、安全、内存、旋转和长稳测试待做。

## 构建

使用 ESP-IDF **v5.5.5**、esp32s3 工具链、CMake/Ninja；保留依赖锁文件。源码和配置默认值不含真实秘密。

```sh
cd firmware/esp32
idf.py set-target esp32s3
idf.py build
CC=clang ./host-tests/run.sh
```

主机测试使用生产 C 解析器与 IDF cJSON，启用地址/未定义行为检测，覆盖未知/零、只读周窗口、截断、过期/未来时间及时间偏移。主机测试不是屏幕、触摸、联网或 TLS 真机证明。

## 私密配置和恢复

管理员创建独立的 Codex 真实只读设备，不用旧全局读取、管理员或采集写令牌。配置 JSON 保存在仓库外的私密目录，权限 600，字段为 `server`、`token`，可选 `ssid`、`password`。Wi-Fi 密码也可在手机配网页填写，不需要发进聊天。

```sh
python tools/provision_nvs.py --config /私密目录/config.json --output /私密目录/pixora-nvs.private.bin
```

工具拒绝在源码仓库内输出私密镜像；应用固件不含用户凭据。NVS 在 `0x9000`、大小 `0x6000`；应用在 `0x10000`，完整启动/分区偏移以 `build/flash_args` 为准。刷入会替换原分区和配置，必须先整片备份。备份可能包含原 Wi-Fi/应用凭据，不上传，不烧写 eFuse，不为跑原型关闭保护。仅对同一块实物、正确原始参数恢复匹配的全片备份。用户设备恢复文件另存私有部署目录。

## Orbit 主题与防误触交互（V0.5 增量）

- 首页采用与手机同语义的同心双圆环；四套主题 Orbit/Paper/AMOLED/Aurora、四种强调色直接由 `web/src/themes.js` 生成 C 色板。运行 `node firmware/esp32/tools/generate_themes.mjs --check` 校验一致性；Aurora在小屏使用静态渐变，未复制网页复杂背景。
- 点击中央额度切换短/长窗口焦点，点击连接状态查看来源/采集时间；设置可切换主题、强调色、动效，独立保存在屏幕NVS。此轮不自动同步手机浏览器本地偏好，也不声称已接入服务端推荐主题。
- 900ms额度过渡与30秒刷新节奏卫星；过期、断网或关闭动效时停止。该动画不表示AI任务正在运行。
- 首页不再直接进入配网；需设置→Wi-Fi setup→确认。查看设置不会暂停采集，确认后才打开配网。网络操作由采集任务处理，不在触摸回调中切网。
- 已配好设备升级只刷应用分区，并保留/验证NVS；不要重新刷初始NVS镜像，否则会覆盖用户Wi-Fi。多Wi-Fi、BOOT长按与Mac BLE桥接仍待后续实现。

### 屏上直接配网
设置 → Wi-Fi setup 现在直接扫描附近2.4GHz网络（最多显示12个不同SSID，可滚动）；选中后使用屏幕键盘输入密码，勾号连接、X取消。常用汉字使用内置字体回退，非完整中文输入法；隐藏网络目前支持ASCII手输，其他名称可走手机备用页。开放网络空密码；WEP/企业认证不支持，不可选择。

试连成功且获取IP并核对SSID后才保存新配置，失败恢复旧连接；取消输入不改配置。密码遮蔽、不回显已保存密码，不上传或写日志。SSID和密码放在单一NVS记录，兼容读取旧键；配置仍未加密，不应宣称抵御物理读取。屏上菜单/连接状态属于本轮待实物验收功能，构建通过不等于实际连接回退已通过。手机热点/网页降为Phone fallback，需要二次确认。此轮仍只保存一套当前网络，多Wi-Fi管理与BLE未实现。

### Mac USB 数据桥接（有线原型）
热点握手不成功时，Mac可读取同一限权HTTPS数据，通过已插USB线传给屏幕。此为有线显示数据桥接，不是BLE或IP网络共享。仓库根目录运行 `python clients/mac_usb_bridge.py --config /path/to/private-config.json`，需 `pyserial==3.5`。配置文件权限600，字段为server、独立显示token、device_id、port，可选usb_serial用于跟随同一实物的端口变化；不能使用管理员/采集器/上游账号凭据。

屏上点击连接状态→Mac USB / ON（默认OFF，保存在本机）。设备每次启动生成随机nonce，并先向Mac证明显示密钥绑定；每帧用该密钥HMAC-SHA256校验并绑定本次nonce/递增序号，密钥不通过USB发送。Mac保持HTTPS证书校验，拒绝重定向。USB只接受显示数据及签名的离线/撤销事件，不接受Wi-Fi配置或任意命令。无SNTP时用已签名Mac时间校时；心跳65秒失联后过期并允许Wi-Fi重试，撤销清屏。

Wi-Fi轮询改为每秒让出处理USB和界面，重连仍按间隔进行。未解决热点问题的传统无线/省电试验已撤回。NVS仍未加密，不宣称抵御物理提取显示密钥。刷机前停止桥接；撤销验收使用独立临时授权。BLE、当前热点直连及屏上操作分别待验收，不能用USB通过替代。

## 屏幕与床头模式

新增外围时间/日期/天气、独立时钟页、闲置唤醒、亮度/夜间调暗和保存后重启的四向旋转。天气必须使用包含 weather 的显示授权；旧 Codex-only 令牌不会自动扩权。完整功能边界与实物步骤见 [屏幕验收](../../docs/ESP32-SCREEN-ACCEPTANCE.zh-CN.md)。自动旋转与BLE尚未实现。
